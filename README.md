# Reap Workplace Agent

[Pitch, PDF y guion de la demo](docs/pitch/README.md): originales verificados con SHA-256, simulación local explícita.

Proyecto independiente y privado para el hackathon Reap. Nombre provisional.

Un expediente de TI que comprueba conexiones, propone reutilizar antes de comprar y requiere aprobación de una cotización concreta. Un pedido confirmado no significa instalación ni incidencia resuelta.

MVP en desarrollo en `feat/local-mvp`. `main` conserva esta base documental estable.

Todo el inventario y catálogo de demostración es sintético. No contiene código ni datos de otros proyectos. No hay pagos reales ni credenciales.

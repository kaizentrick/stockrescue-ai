# Dirección visual

Premisa: un expediente de TI donde la conexión comprobada precede al gasto y cada decisión conserva su evidencia.

Se exploraron tres composiciones: secuencia guiada, índice con expediente continuo, matriz de conexiones con transacción lateral. Dentro del desarrollo independiente delegado se eligió índice + expediente: permite consultar puertos y razones sin abandonar la autorización. Tres especialistas independientes revisaron el concepto antes de implementar.

El índice identifica el puesto; el expediente presenta conclusión, inventario, alternativas, compra cuando procede y bitácora. En ancho reducido el selector nativo precede al expediente y las tablas conservan relaciones mediante desplazamiento local. Tipografía de sistema por legibilidad operativa, números tabulares para comparar importes, tinta azul para lectura y verde oscuro solo para acción/decisión. Reglas y espacio separan contenido, sin tarjetas ni decoración.

No se usa marca oficial ni se inventa un nombre comercial. El título es provisional. No hay imágenes, datos de clientes, claims de demanda ni prueba social.
